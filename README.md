# 读懂鲁月佳 · 三天

一个纯前端、零依赖的三天文字养成游戏。打开 `index.html` 即可玩，无需构建、无需后端。

**在线试玩：** https://scforver-alt.github.io/luyuejia/

## 她是谁

鲁月佳，1999.06.14，双子座，属兔，二十七岁，被工作磨得有点钝的上班族。
话不多，不太爱解释自己，按自己的节奏过日子。难受的时候，她会把话说硬，然后把自己收起来——
不是没有情绪，只是太习惯自己消化。这个游戏要你做的，是听出那句硬话底下的那半句。

## 玩法

- **8 道摸底题**决定初始面板。偏爱度开局上限 40——答得再准，她也不会一上来就把人放进来
- **三天**：周五加班夜 / 周六 / 周日，每天三个事件，走完可发起一次主动互动
- **五项属性**：内耗（反向，需 ≤20）、松弛度、兴致、信任值、偏爱度（其余需 ≥80）
- **四项隐藏数值**：记忆印记、刺的浓度、退缩倾向、自我接纳
- **长线**：试刺线 / 消失线 / 她说人话线 / 她第一次反过来，外加极限抉择与周日深夜的终局提问
- **8 种结局**，由属性、长线完成度与隐藏数值共同决定
- 每次选择都有反馈：对了落爱心，错了落眼泪，不对不错是一脸微笑

## 技术

单文件 HTML，内联 CSS 与 JS，唯一外部资源是 Google Fonts。
进度存在浏览器 `localStorage`，不上传任何数据，不含任何密钥或后端调用。
